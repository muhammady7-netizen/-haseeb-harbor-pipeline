# One-line chat access

After `git pull` / clone of https://github.com/muhammady7-netizen/-haseeb-harbor-pipeline

| Say in Cursor | Open / paste |
|---------------|--------------|
| **chat A** | `sessions/A/PROMPT.md` |
| **chat B** | `sessions/B/PROMPT.md` |
| **chat C** | `sessions/C/PROMPT.md` |
| **chat D** | `sessions/D/PROMPT.md` |
| **chat E** | `sessions/E/PROMPT.md` |
| **chat F** | `sessions/F/PROMPT.md` |

Each folder has:
- `PROMPT.md` — full agent instructions + commands
- `tasks.txt` — task shorts + IDs
- `zips/` — upload zips for that chat’s tasks

```powershell
git clone https://github.com/muhammady7-netizen/-haseeb-harbor-pipeline.git
cd -haseeb-harbor-pipeline
git pull
# then paste sessions/A/PROMPT.md into a new chat
```
