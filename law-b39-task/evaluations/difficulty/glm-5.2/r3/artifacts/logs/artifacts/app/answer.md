# Review of the draft letter against the client's record

The draft letter has been checked line by line against the first message and the later clarification, using the review protocol to identify which entry governs each subject. Where the clarification speaks to a subject, it prevails over the original instruction; where the clarification leaves a subject alone, the original instruction still governs; and where neither record addresses a subject, the line is not in the record at all. The cross-subject citation exception was also applied, so a line that cites a clarification entry for a different subject is weighed against the original instruction entry for its own subject rather than against the clarification.

Many lines are verified by the governing record, but a number of lines take positions that conflict with the client's actual instructions. Some lines are narrower than the governing entry, some reverse the person identified, and some raise subjects that the client never addressed in either message. The review table records the verdict and governing entry for every numbered line, and the totals are set out in the JSON file.
